# Library Management System

A comprehensive library management system built with Django REST Framework backend and React frontend.

##  Features

- **Book Catalog Management**: Browse, search, and manage book inventory
- **Loan Processing**: Handle book loans and returns with tracking
- **User Management**: User authentication and profile management
- **API Integration**: RESTful API connecting frontend to backend
- **Admin Interface**: Django admin panel for system administration
